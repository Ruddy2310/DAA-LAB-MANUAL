How merge sort works

  1. Split the list in half again and again, until every piece is a single bar. One bar is already sorted.
  2. Merge two sorted pieces into one. Look at the first bar of each piece and always take the smaller one.
  3. Keep merging bigger and bigger pieces until the whole list is one sorted run.

Good for big lists, because it stays fast. It needs extra space to merge. Steps grow roughly with n × log n.

About this project

What it is

An interactive page that shows how merge sort works, one step at a time. You can watch every comparison and every move.

The main idea

Each number is a bar. A taller bar means a bigger number. Sorting means arranging the bars from shortest to tallest.

How I built it

  1. Made a random list of numbers and showed each number as a bar.
  2. Made merge sort run one small step at a time, so it can be paused and stepped through.
  3. After every step, the bars change color and a simple line explains what happened.
  4. Added counters, so we can see how many comparisons it needs.

Why merge sort is fast

With 100 bars it needs only a few hundred comparisons. Bubble sort needs about 5,000 for the same list.

The code (simplified)

function* mergeSort(a, l, r) {
  if (r <= l) return;                  // one bar is already sorted
  const m = Math.floor((l + r) / 2);     // find the middle

  yield* mergeSort(a, l, m);             // sort the left half
  yield* mergeSort(a, m + 1, r);         // sort the right half

  const L = a.slice(l, m + 1);           // copy of left half
  const R = a.slice(m + 1, r + 1);       // copy of right half
  let i = 0, j = 0, k = l;

  while (i < L.length && j < R.length) {
    yield 'compare';                     // pause so the page can show it
    a[k++] = L[i] <= R[j] ? L[i++] : R[j++];  // take the smaller bar
  }
  while (i < L.length) a[k++] = L[i++];  // left bars still remaining
  while (j < R.length) a[k++] = R[j++];  // right bars still remaining
}

Both halves get sorted first, then they are merged by always taking the smaller front bar. The yield line pauses the code, so the page can show each step.

How to present it

  1. Press Play at 16 bars and explain the colors.
  2. Use Step a few times and read the explanation line out loud.
  3. Set bars to 100 and run it fast. Point at the comparison counter.
